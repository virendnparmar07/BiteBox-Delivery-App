# 🍔 BiteBox — Food Delivery Website

**BiteBox** is a food delivery website built using HTML, CSS, and JavaScript. It provides a simple and user-friendly interface for exploring food items, viewing deals, and managing a shopping cart.

## 🌟 Features

* 🏠 **Home Page:** A welcoming landing page with food promotions and featured content.
* 🍕 **Food Menu:** Browse food items and explore available options.
* 🔥 **Bite Deals:** A dedicated page for displaying special food offers.
* 🛒 **Shopping Cart:** View and manage selected food items.
* 🔐 **User Authentication UI:** Separate login and signup pages.
* 🎨 **Custom Styling:** A distinctive red-and-black visual theme with food-focused design.
* 📱 **Responsive Design:** Aiming to provide a consistent experience across different screen sizes.

## 🛠️ Technologies Used

* **HTML5** — Website structure and content.
* **CSS3** — Styling, layouts, and responsive design.
* **JavaScript** — Interactive features and website functionality.
* **Font Awesome** — Icons.
* **Google Fonts** — Custom typography.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/BiteBox.git
```

### 2. Open the project folder

```bash
cd BiteBox
```

### 3. Run the website

Open `index.html` in your preferred web browser.

Alternatively, use the **Live Server** extension in Visual Studio Code to run the website locally.
